# 본가ON — 경주본가 가맹점 운영 플랫폼 (MVP)

가맹점 사장님용 월정액 SaaS. 통합 매출 대시보드 · AI 리뷰 답글 · 본사 발주 · 공지를 하나의 앱으로 제공합니다.

## 실행

```
cd bonga-on
npm install
npm start
```

→ http://localhost:8321

첫 실행 시 `bonga-on.db`(SQLite)가 자동 생성되고 데모 데이터가 채워집니다.

## 데모 계정 (비밀번호 모두 `bonga1234`)

| 아이디 | 역할 | 플랜 |
|---|---|---|
| `suwon` | 가맹점 (수원인계점) | 프로 — AI 답글 사용 가능 |
| `gangnam` | 가맹점 (강남점) | 베이직 — AI 답글 잠김(요금제 차이 체험) |
| `hq` | 본사 관리자 | 지점 현황 / 발주 상태 관리 / 공지 작성 |

## AI 리뷰 답글

환경변수 `OPENROUTER_API_KEY`가 있으면 OpenRouter 경유로 실제 LLM이 브랜드 톤 답글을 생성합니다
(기본 모델 `anthropic/claude-haiku-4.5`, `OPENROUTER_MODEL`로 변경 가능).
키가 없으면 규칙 기반 기본 답글로 대체되어 기능 자체는 항상 동작합니다.

## 구현된 것

- 세션 로그인 (bcrypt 해시, 가맹점/본사 역할 분리)
- 대시보드: 어제 매출·전주 대비 증감·채널별 집계·7일 차트 (전부 DB 실시간 집계)
- 매출 일별 기록 (배달앱 API 자동연동 전까지의 수동 입력)
- 리뷰: 답글 대기 필터 → AI 초안 생성 → 수정 → 등록 (DB 저장)
- 발주: 품목 장바구니 → 접수 → 본사가 상태 변경(접수→확정→배송중→완료) → 가맹점에 반영
- 공지: 본사 작성 → 가맹점 읽음 처리 → 대시보드 새 공지 카운트
- 요금제: 베이직/프로 기능 게이팅 (AI 답글은 프로 전용, 402 응답)

## 다음 단계 (실서비스 로드맵)

1. **배달앱 연동** — 배민/쿠팡이츠는 공식 오픈 API가 없어 사장님 계정 연동(세션 기반 수집) 방식 필요. 법적·기술적 검토가 가장 큰 산.
2. **결제** — 토스페이먼츠 빌링(정기결제) 연동으로 월정액 자동 청구.
3. **배포** — 현재 구조 그대로 VPS(예: 라이트세일)에 올리거나, Next.js + Supabase로 이전 후 Vercel 배포.
4. **알림** — 부정 리뷰(3점 이하) 등록 시 카카오 알림톡/푸시.

## 기술 스택

Express + Node 내장 SQLite(`node:sqlite`) — 외부 DB 설치 불필요. 프론트는 순수 HTML/JS.
