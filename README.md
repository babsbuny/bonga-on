# 한큐배달 — 외식 매장 운영 월정액 SaaS

가맹점·매장 사장님용 구독 플랫폼. 통합 매출 대시보드 · AI 리뷰 답글 · 본사 발주 · 공지를 하나의 앱으로 제공합니다.
경주본가는 첫 데모 고객사(테넌트)이며, 다른 외식 브랜드에도 판매할 수 있도록 브랜드 정보는 데이터로 분리되어 있습니다.

- **라이브**: https://hanq-delivery.vercel.app
- **저장소**: https://github.com/babsbuny/hanq-delivery

## 실행 (로컬)

```
npm install
npm start
```

→ http://localhost:8321 · 로컬에서는 Node 내장 SQLite(`hanq.db`)가 자동 생성됩니다.

## 데모 계정 (비밀번호 모두 `bonga1234`)

| 아이디 | 역할 | 플랜 |
|---|---|---|
| `suwon` | 가맹점 (경주본가 수원인계점) | 프로 — AI 답글 사용 가능 |
| `gangnam` | 가맹점 (경주본가 강남점) | 베이직 — AI 답글 잠김 |
| `hq` | 본사 관리자 | 지점 현황 / 발주 관리 / 공지 작성 |

## 아키텍처

- **DB**: 배포 환경에서는 Supabase Postgres(`POSTGRES_URL` 감지 시), 로컬은 SQLite — [data.js](data.js)가 두 백엔드를 같은 API로 감쌉니다.
- **세션**: 서명된 쿠키(cookie-session) — 서버리스에서도 로그인 유지.
- **AI 답글**: `OPENROUTER_API_KEY`가 있으면 실제 LLM(기본 `anthropic/claude-haiku-4.5`)이 브랜드 톤 답글 생성, 없으면 규칙 기반 대체. 브랜드명은 계정의 `brand` 값에서 가져옵니다.
- **배포**: GitHub `main` 푸시 → Vercel 자동 배포. `render.yaml`로 Render 배포도 가능.

## 구현된 것

- 세션 로그인 (bcrypt, 가맹점/본사 역할 분리)
- 대시보드: 어제 매출·전주 대비 증감·채널별 집계·7일 차트 (DB 실시간 집계, KST 기준)
- 매출 일별 수동 기록 (배달앱 API 자동연동 전 단계)
- 리뷰: 답글 대기 필터 → AI 초안 → 수정 → 등록
- 발주: 장바구니 → 접수 → 본사 상태 변경(접수→확정→배송중→완료) → 가맹점 반영
- 공지: 본사 작성 → 가맹점 읽음 처리 → 새 공지 카운트
- 요금제 게이팅: AI 답글은 프로 전용(402)

## 다음 단계 (실서비스 로드맵)

1. **멀티 브랜드(테넌트)** — 브랜드 가입/온보딩, 브랜드별 품목·계정 관리 화면.
2. **배달앱 연동** — 배민/쿠팡이츠는 공식 오픈 API가 없어 사장님 계정 연동 방식 필요. 법적·기술적 검토 필수.
3. **결제** — 토스페이먼츠 빌링(정기결제)으로 월정액 자동 청구.
4. **알림** — 부정 리뷰(3점 이하) 등록 시 카카오 알림톡/푸시.
5. **AI 키 설정** — Vercel 환경변수에 `OPENROUTER_API_KEY`를 넣으면 라이브에서도 실제 AI 답글 동작.
